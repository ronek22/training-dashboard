Where am I in the arc
Critique: Plan shows a good week but an island: the header says "Week 45", which is a calendar fact, not a training one. The arc (base → build → VO2) and the stall block live only on the web, so a lighter week or a lift that changed looks arbitrary on the phone. Nothing else needs to go: the week card and rows already carry the week. This adds one thin strip with one picture, the arc tape: a segment per week, so where you are, how far you've come and what's coming read at a glance, and the words only label it. No analysis on Plan; detail behind a tap.

Notes
Data, build and what's made up
Data (existing routes, no backend change)
  • GET /plans/winter-arc: blocks[] with start/end, weeks, label, focus label, weekly hours, ride mix, lighter_weeks, and status (none / upcoming / active / gap / finished).
  • GET /strength/workouts/stall-blocks?status=active: exercise, label, plan text, started/ends, week, weeks, due.
  • The phone works out the selected week's position from the blocks, so paging to week 44 or 46 (even unplanned) moves the marker without another call. Both cached for offline like the week.
Build
  • One ArcStrip view (tape + line + optional stall line) under ScreenHeader, as a plain row; ArcSheet at the medium detent.
  • Pure ArcFormat: week position, "lighter next" / "X next" / "starts Mon 16 Nov", stall text; unit tests for every state on this board.
  • -arcDemo active|lighter|upcoming|none|stall launch flag for screenshots, no server writes.
  • Not on the phone: the extend/accept suggestion when life ate a week (stays on the web strip).
Live vs made up
  • Live on 5 Nov: week 45 (titles, sports, minutes, 3 of 7 done), no winter arc saved, one active stall block: Upright row rep scheme, 3 × 12–15 at 18 kg, Oct 12 – Nov 2, due.
  • Made up: the arc in 01–04 (Base / Sweet-spot build / VO2 touch from Oct 19, shaped like the web's Nov–Feb template), the Bench block, "starts Mon 16 Nov".
  • Week card and rows match the simulator on 5 Nov.
