Notes
Design language and data
The tape
  • One component, four uses: Today (pace), Pace guide header (bigger), After-run (your pace as a needle), Saved (next run). Return-to-run swaps pace for minutes.
  • Ticks every 2 s, taller every 10 s and 30 s; inside the zone the ticks are orange and 5 pt taller. Zone edges get hairlines up to the numbers.
  • One big number group per screen. Kickers: at most one per block. Everything else: 13 pt soft text.
  • Volt only for the win (05). Teal = walk / easy feel; orange = run.
Where it shows
  • Today card when the day is a run (01) or a return-to-run step (03). The whole card opens the guide; Swap day moves to long-press.
  • Pace guide is a pushed page, not a tab.
  • After-run sheet opens once per new run on Today; later from the run's detail page.
  • Felt dates in 02/05 are illustrative: the history starts empty.
Data
  • Pace, VDOT, projection, peak, HR cap: GET /running/fitness. Step: GET /return-to-run.
  • Knee: existing PUT /activities/{id}/symptoms.
  • Felt: new PUT /activities/{id}/felt (easy|ok|hard, queued offline). The existing feedback POST requires RPE, energy and soreness, so it stays untouched.
  • Two hard in a row → band +10 s/km, computed in /running/fitness so the web shows the same band.
