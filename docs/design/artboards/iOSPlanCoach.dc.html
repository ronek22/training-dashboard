Notes
Flow, backend and data
Flow
  • Plan (03 → 04 → 05): from week 46's empty card. Brief optional. On success the Plan tab reloads and lands on the new week.
  • Refine (06 → 04 → 07): from the header sparkle. Needs text. Works on the current week and on next week once it exists.
  • One day (08): from Plan day. Same working and result sheets, one row.
  • One coach job at a time; while one runs, the other entry points show the progress line instead of a button.
  • Strip day tap inserts "Thu: " at the caret; tapping again removes it if the line is empty.
Backend (new routes only)
  • POST /plans/weekly/coach {week_start, planning_brief} → 202 {job_id}
  • POST /plans/weekly/coach/revise {week_start, feedback, target_date?} → 202 {job_id}
  • GET /plans/weekly/coach/{job_id} → {status, message, summary, started_at}
  • GET /plans/weekly/coach/status → helper up / busy, for 09.
  • Relay like coach_chat_relay: backend calls the helper's /weekly-plan and /weekly-plan-revision. The web keeps calling the helper directly.
  • "What changed" reads the plan's latest_revision.changed_dates plus the before/after days the phone already has.
