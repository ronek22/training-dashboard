Rules and data
When and what
  • Switch: 20:00 to 03:59 local, title TODAY → TONIGHT. Pull to refresh doesn't switch back; the morning brief hour takes over at 04:00.
  • The branch: planned main part done (isDone) → the day-strip card leads. Not done → Still on today leads, with its ghost block drawn on the Tonight runway.
  • Fits? now + session minutes ≤ wind-down (lights out − 45): volt Start · done by HH:MM. Otherwise volt Move day, outline Start anyway and Let it go.
  • Readiness card is hidden in the evening (it reads last night; Body still has it). Week card stays at the bottom. The wins row folds into the recap card's chips; protein moves to the food row so nothing shows twice.
The one line
  • Rule-built, no AI: [session state], [outside]. [close]. Session: “Lift done” / “lift still open” / “Rest day kept” / “Sick day N”. Outside: ≥ 30 min “46 minutes in daylight”, 1–29 “only 12 minutes outside”, 0 “no daylight yet today”.
  • Close: a clean day → “Close it here.”; rest day with ≥ 30 min → “That counts.”
  • Time outside: HealthKit timeInDaylight (Watch, iOS 17+), read on the phone like steps. Steps hourly as Body already reads them. Sunset from a home location (see question).
Data
