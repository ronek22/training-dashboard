Critique of Body today
  1. The map answers “what is ready?”. Grey (“rested”) means both fresh and neglected: legs at 0 sets look calm.
  2. What worked what counts sessions over a rolling 7 days with no target, so it can’t say “short”.
  3. Nothing links a gap to the plan: the planner already adds extra sets to Fri/Sat, but the phone never shows it.
Data
  • Live from /plans/weekly → lift_volume (week of 2 Nov): legs 0 (knee protected), back 3 + 11 planned, chest 3 + 5 planner extras, shoulders 18 + 19, arms 9 + 11. Core isn’t a target group, so it’s left out.
  • New: a light coverage block on /phone/body (groups + upcoming lift days with sets per group). Existing shapes unchanged.
  • “Hard sets” = logged working sets this week (Mon–Sun) by primary group, the planner’s count.
Nudge rule
  • Pick the targeted group furthest below 8 in logged sets (skip protected / hiking).
  • Walk upcoming lift days (today if not lifted yet): one day reaches 8 → “Saturday’s lift can fix it”; two → “Friday and Saturday close it”; never → “Friday takes it to 6”; none → “no lift days left this week”.
  • Never suggests fewer lifts; only names days already planned.
